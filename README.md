# Adarsh & Co. | Chartered Accountants

The official website for **Adarsh & Co.**, a Chartered Accountancy firm in Bengaluru. It's a responsive, multi-page static site built with plain HTML and CSS.

![Homepage](Screenshot-Capture-2023-12-04-15-58-14.png)

## Pages

- **Home, About, Team, Contact**
- **Services:** Audit & Assurance, Accounting, Direct Tax, GST, Advisory
- **Careers**, with an application page

## Stack

HTML5, CSS3 (`css/style.css`), no framework or build step. It includes a full favicon set and a WhatsApp contact shortcut.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
